# Old Standard TT Regular

Designed by Alexey Kryukov and the Old Standard Project Authors. Distributed under the SIL Open Font License 1.1; see `OFL.txt`.

The regular Latin webfont was downloaded from [Google Fonts](https://fonts.google.com/specimen/Old+Standard+TT) on 1 November 2026. It is retained in TrueType format with the glyphs and font names unchanged. Its letter outlines were used to typeset the decorative paragraphs in `assets/images/hero-book-text.svg`; the browser displays that vector background and does not download this source font.

- Original font file: https://fonts.gstatic.com/s/oldstandardtt/v22/MwQubh3o1vLImiwAVvYawgcf2eVeqlq4.woff2
- License source: https://github.com/google/fonts/blob/main/ofl/oldstandardtt/OFL.txt
- Typeface background: https://ctan.org/pkg/oldstandard
